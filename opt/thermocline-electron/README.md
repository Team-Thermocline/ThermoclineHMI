# Thermocline Electron

Electron application that runs the sender component fullscreen.

## Building

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run in development:**
   ```bash
   npm start
   ```

3. **Package the application:**
   ```bash
   npm run package
   ```

4. **Create distributables:**
   ```bash
   npm run make
   ```
